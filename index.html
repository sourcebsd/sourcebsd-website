about

SourceBSD — это попытка собрать систему с нуля, без чужих библиотек, без systemd, без wayland.

Всё, что тут есть — написано вручную. Ядро, libc, утилиты, загрузчик.

  • микроядро — x86_64, ARM, RISC-V
  • своя libc (libsource)
  • свой компилятор (tcc) и линкер (self-ld)
  • rc.d вместо systemd
  • wayland выключен намеренно
  • свой пакетный менеджер — intensive / srcpkg
  • контейнеры (scontainer) — без docker'а
  • встроенный httpd
  • шифрование диска

Размер всей системы — меньше 100 КБ.

— написано за ночь, работает с утра.

install (быстро)

  1. скачай образ (ссылки в разделе docs)
  2. запиши на флешку: dd if=sourcebsd.iso of=/dev/sdX bs=1M
  3. загрузись, выбери 1
  4. запусти ./installer
  5. напиши yes
  6. после перезагрузки: user / password

— этого достаточно, если не хочешь вникать.

guide — снос и установка

Этот гайд — для тех, кто хочет стереть текущую систему (Windows, Linux, что угодно) и поставить SourceBSD без ISO.

⚠️ ВНИМАНИЕ: диск будет полностью стёрт. Без возврата.

способ 1 — скрипт (ленивый вариант)

wget https://sourcebsd.org/install.sh chmod +x install.sh sudo ./install.sh

Скрипт спросит диск, сотрёт его, создаст раздел, скопирует систему, поставит загрузчик.

способ 2 — руками (для понимания)

Загрузись в любой LiveCD (Ubuntu, Arch, Gentoo — не важно).

  1. посмотри диски: lsblk
  2. сотри MBR: dd if=/dev/zero of=/dev/sda bs=1M count=10
  3. создай раздел:
    fdisk /dev/sda
    • o — новая таблица
    • n → p → 1 → Enter → Enter
    • a → w
  4. форматируй: mkfs.ext4 /dev/sda1
  5. монтируй: mount /dev/sda1 /mnt
  6. скопируй систему:
    git clone https://github.com/sourcebsd/src /mnt/usr/src
  7. настрой пользователя:
    echo "user:password" | chpasswd -R /mnt echo "root:password" | chpasswd -R /mnt
  8. загрузчик: dd if=/mnt/boot/sourceboot.bin of=/dev/sda bs=512 conv=notrunc
  9. перезагрузиcь: reboot

— после загрузки логин user / password.

скрипт целиком

Сохрани как install.sh:

#!/bin/sh # SourceBSD — полный снос и установка set -e if [ "$(id -u)" != "0" ]; then echo "запусти с sudo" exit 1 fi echo "диски:" lsblk echo "целевой диск (например /dev/sda):" read DISK if [ -z "$DISK" ]; then exit 1; fi echo "стереть $DISK? (yes/no)" read CONFIRM if [ "$CONFIRM" != "yes" ]; then exit 1; fi echo "[+] стирание..." dd if=/dev/zero of=$DISK bs=1M count=10 echo "[+] раздел..." echo -e "o\nn\np\n1\n\n\na\nw\n" | fdisk $DISK echo "[+] формат..." mkfs.ext4 ${DISK}1 echo "[+] монтирование..." mount ${DISK}1 /mnt echo "[+] копирование..." git clone https://github.com/sourcebsd/src /mnt/usr/src echo "[+] пользователи..." echo "user:password" | chpasswd -R /mnt echo "root:password" | chpasswd -R /mnt echo "[+] загрузчик..." dd if=/mnt/boot/sourceboot.bin of=$DISK bs=512 conv=notrunc echo "[+] готово. перезагружай." echo "логин: user | пароль: password"

запуск:

chmod +x install.sh sudo ./install.sh

build from source

Собрать вручную:

git clone https://github.com/sourcebsd/src /usr/src/sourcebsd cd /usr/src/sourcebsd ./build.sh

После сборки — kernel.bin и initrd.cpio.gz.
